# Event-Responsive Robust DEA

Replication materials for the research study on event-responsive robust data envelopment analysis (DEA).

## Research overview

This project develops and empirically examines a robust DEA framework that incorporates event-responsive uncertainty in input and output measurements.

## Repository contents

The repository will contain:

- Analysis code and computational procedures.
- Data preparation and uncertainty-calibration materials.
- Processed data permitted for public distribution.
- Instructions for reproducing the reported results.

## Data availability

Data sources, access conditions, and instructions for obtaining the data will be documented here. Any data subject to third-party restrictions will not be redistributed.

## Reproducibility

Detailed instructions, software requirements, and execution order will be added with the replication files.

The manuscript citation will be added after publication.
